# prestashopheaven/build-pitfalls

The pitfalls index of the Module-Factory: every known pitfall from the Notes of the module repos (CONTEXT.md), the feature recipes and a curated list, searchable before a module is designed or built.

## Use when

Before designing or building a feature: search what went wrong before in the same area (ps-module find --pitfalls  <area> ), so a lesson from one module reaches the next.

## Install

```
composer require prestashopheaven/build-pitfalls
```
